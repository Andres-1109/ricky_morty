# Rick & Morty Characters

SPA que lista personajes de la API pública de Rick & Morty con paginación, roles (admin/visitante) y navegación History API.

| Stack | Versión |
|-------|---------|
| Vite | 8.x |
| Tailwind CSS | 4.x |
| Vanilla JS | ES modules |
| Backend | json-server (db.json) |
